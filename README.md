# Operating Systems Project

This project was developed as part of the Operating Systems course at the School of Electrical Engineering, University of Belgrade.

The project is written in C++ and RISC-V assembly and includes basic operating system functionalities such as memory management, threads, scheduling, semaphores and system calls.

The `inc` folder contains header files, while the `src` folder contains the implementations.

**Note:** Only my implementation is included in this repository. Additional files and libraries provided by the faculty are required to compile and run the project.
